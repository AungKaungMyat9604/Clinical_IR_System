# Report (IEEE Conference LaTeX)

The portfolio report uses the **IEEE Conference** template (`IEEEtran`).

- **Source:** [`report.tex`](report.tex)
- **Authors:** Aung Kaung Myat and Zarni Hlawn
- **Class file:** [`IEEEtran.cls`](IEEEtran.cls) (local copy)

## Build

From the `Report/` directory:

```bash
pdflatex report.tex
pdflatex report.tex   # run twice for stable references
```

Output: `report.pdf`
